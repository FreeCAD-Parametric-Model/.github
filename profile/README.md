# FreeCAD - Parametric Model, Part Design, and Sketch Editor

## About FreeCAD

FreeCAD is parametric CAD for a part you own. FreeCAD Parametric Model is the file. FreeCAD Part Design is the solid. FreeCAD Sketch Editor is the 2D start. FreeCAD Workbench List is the set of tools you actually use. FreeCAD Assembly View is how several parts sit together.

Open a file you own. Start FreeCAD Sketch Editor on a plane you can find later. Build FreeCAD Part Design from that sketch. Keep FreeCAD Workbench List short. Use FreeCAD Assembly View only when more than one part must move together. FreeCAD Parametric Model should stay named after the job.

FreeCAD Parametric Model, FreeCAD Part Design, FreeCAD Sketch Editor, FreeCAD Workbench List, and FreeCAD Assembly View exist to change a solid you already have a reason to change.

Do not leave unnamed features. Do not load every item in FreeCAD Workbench List. Do not explode FreeCAD Assembly View into a pile you cannot rebuild. Save before a boolean you cannot name. FreeCAD Sketch Editor should stay fully constrained when the part must survive a later edit.

## Key Features of FreeCAD

- **Parametric model as the file** – FreeCAD Parametric Model is the document. FreeCAD Part Design lives in it. FreeCAD Sketch Editor lives in it. FreeCAD Workbench List does not replace a named file. FreeCAD Assembly View is another document or a container you still name.
- **Part design as the solid** – FreeCAD Part Design is the body you change. Start in FreeCAD Sketch Editor. FreeCAD Parametric Model then has a history. FreeCAD Assembly View consumes that body. FreeCAD Workbench List should still include Part Design if that is the job.
- **Sketch editor as the 2D start** – FreeCAD Sketch Editor is lines and constraints. Fully constrain it. FreeCAD Part Design pads from there. FreeCAD Parametric Model rolls back to that sketch. FreeCAD Assembly View does not fix a loose sketch. FreeCAD Workbench List should not hide the sketch tool.
- **Workbench list as a short set** – FreeCAD Workbench List is extra modules. Enable what you use. FreeCAD Part Design should still open. FreeCAD Sketch Editor should still constrain. FreeCAD Parametric Model should still save. FreeCAD Assembly View should still mate.
- **Assembly view as several parts** – FreeCAD Assembly View is mates, not a sculpture. Each part is still a FreeCAD Parametric Model. FreeCAD Part Design still owns the solid. FreeCAD Sketch Editor still owns the 2D. FreeCAD Workbench List still needs the assembly workbench you actually use.

## Quick Start with FreeCAD

1. **One sketch** – New FreeCAD Parametric Model. Open FreeCAD Sketch Editor. Ignore FreeCAD Assembly View. Ignore extra FreeCAD Workbench List. Pad once in FreeCAD Part Design.
2. **Name features** – Rename the pad in FreeCAD Part Design. Keep FreeCAD Sketch Editor constrained. Save FreeCAD Parametric Model. Still no FreeCAD Assembly View. Recheck FreeCAD Workbench List is short.
3. **Second body only if needed** – Another sketch in FreeCAD Sketch Editor. Another feature in FreeCAD Part Design. Optional FreeCAD Assembly View if two files must mate. FreeCAD Parametric Model still named. FreeCAD Workbench List still short.
4. **Export a format you open** – From FreeCAD Parametric Model, export a step you still open. FreeCAD Part Design unchanged. FreeCAD Sketch Editor unchanged. Skip FreeCAD Assembly View if it is a single part. Skip extra FreeCAD Workbench List.
5. **Review** – Unnamed features gone. FreeCAD Sketch Editor still constrained. FreeCAD Part Design history readable. FreeCAD Workbench List still few. FreeCAD Assembly View only if mates exist. FreeCAD Parametric Model still the job name.
